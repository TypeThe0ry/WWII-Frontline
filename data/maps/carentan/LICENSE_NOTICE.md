## Vector layers (`roads`, `hedgerows`, `buildings`, water): ODbL 1.0

Data derived from OpenStreetMap is licensed under the Open Database License (ODbL) 1.0.

© OpenStreetMap contributors. https://www.openstreetmap.org/copyright

The vector data layers under `data/maps/carentan/` are declared ODbL (derivative database) and are
published under it (BRIEF R9, default; final confirmation pending in H-004). Game code and
assets are not covered by this notice (Produced Work / collective database separation).

## Elevation

- IGN LiDAR HD and IGN RGE ALTI: Licence Ouverte / Etalab 2.0, attribution required:
  "Source : IGN" (not yet verified at the official page, H-052).
- Copernicus DEM GLO-30 (far ring fallback): "Copernicus DEM GLO-30 (Copernicus WorldDEM-30) ©
  DLR e.V." (not yet verified, H-052).

## Historical imagery and maps

Aerial photographs and period maps (IGN Remonter le temps, NARA, GSGS, IWM) are used only as a
tracing reference and are **not** included in this repository. IWM imagery is never embedded.
