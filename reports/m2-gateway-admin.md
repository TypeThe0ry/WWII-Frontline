# M2-023 网关管理 API 与举报验收

2026-11-20，共享工作站（PI-109，非参考机）。任务状态 `partial`。接口和运维配置见 [网关 README](../crates/gateway/README.md)，设计偏差见 PI-B6-gwadmin-1。

| 项目 | 本地证据 |
| --- | --- |
| 管理鉴权与审计 | 文件型 SQLite 集成测试覆盖允许和拒绝请求、IPv4/IPv6、可信代理链和伪造转发头。注入首次审计插入、最终结果写入故障，均返回 500 且封禁没有生效。 |
| 封禁与管理动作 | 账号、访客令牌指纹、IPv4/IPv6 网段换票封禁，永久身份封禁和 1 h + 1 s 自动恢复。公告发布与过期、服务器隐藏、举报结案与踢人队列均有 HTTP 测试。 |
| 举报 | 同一稳定身份换票后仍执行去重及跨局限速。拒绝 60 秒内的第二个不同举报及同局第 11 个。重复请求返回原举报 ID。赛事指令与举报均走现有比赛服认证链路。 |
| 数据保留 | 注入时钟并重开数据库验证 14/30/365 天保留窗。验证聊天快照更新与比赛结束后不可访问。 |
| 鉴权耗时 | 文件型 SQLite、进程内 Axum、发布构建。错误令牌和不在白名单的来源各 1,000 次，P95 分别 67.629 µs、68.600 µs，相差 0.971 µs（合并 gwstats 后复测）。 |
| 举报列表耗时 | 预置 1,000 条开放举报，100 次分页列表请求，P95 751.114 µs。其他管理接口 P95、参考机和正式环境未测。 |
| 真实进程联测 | 两个实际 WS 无头客户端走签票、C0 举报、写回放、管理结案和踢出。网关挂载 270 B 回放，包含比赛服接纳的目标输入。踢出请求至 C0 `KICKED` 189.5 ms，连接关闭，网关收到 `applied` 回执。另用比赛服对测试网关联测禁言、广播、重试回执和陈旧 JTI。真实网关的禁言传播耗时未测。 |
| 并发签票回归 | `python3 scripts/gateway-ticket-load.py target/release/frontline-gateway --protocol-version 4 --concurrency 200 --runs 5`。身份关联并入签票批次后，每轮签发 200 个唯一票据，合计 1,000 个，0 失败和 0 重复。各轮 P95 17.735、18.930、21.923、15.052、18.431 ms。 |
| sim 确定性 | 严格 Native/WASM 对照，各 2 次 × 3 seed × 18,000 tick。每 tick 哈希和位置一致。 |

比赛服按身份保存输入与关键事件的短片段。回放引用在文件写入完成后登记。在线强制换队与换图返回 `unsupported`。举报附带举报者可见的最近 20 条文字聊天，不采集举报后的 20 条。生产白名单、联系人和正式社区处置见 H-065/H-075。

环形证据缓冲的 100 人峰值内存未测。比赛服当前结算的战绩明细和违规计数尚未接通，管理摘要提供可归属的结果与举报计数。
