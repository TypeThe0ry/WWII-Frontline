# M1-002 · LOD0 尺寸与质量复测（2026-11-20）

## 同输入比较

按 PI-033 使用 `lods[0].bytes / source_bytes`。分子是含全部 KTX2 与 mip 的完整 GLB，分母是 normalized glTF JSON、BIN 和源图片的字节数。工作站为双路 AMD EPYC 7402，本次只用 CPU（PI-109，非参考机）。

| 输入 | 源字节 | LOD0 字节 | 比例 | 耗时与范围 |
|---|---:|---:|---:|---|
| B，改动前 | 5,294,362 | 1,666,732 | 31.48% | 11.13 s，ingest → normalize → process |
| B，改动后 | 5,294,362 | 1,288,944 | 24.35% | 19.54 s，同上，预算 30 s |
| A，改动后 | 10,415,684 | 1,530,052 | 14.69% | 27.5 s，process |

B 使用 `sphereData(160,157)`、albedo seed 3 和 4 张 1024² PNG。两次用同一生成器，旧管线在这份输入上也得到历史记录的 31.5%。历史 B 的输入哈希未保存。A 使用 19,800 三角和 2048² albedo，其余三图各 1024²。

## 取舍与验收 2–8

背景法线沿用 UASTC level 1、Zstd 和 RRRG，在编码时启用率失真优化（λ=2）。B 上法线从 1,125,899 B 减至 748,119 B，保留 1024²、2 通道、11 级 mip。背景颜色与 ORM 仍用 ETC1S。已解码的 RGBA 直接传给编码器，省去临时 PNG 往返。英雄资产与 UI 保留原编码参数，每贴图 profile 可覆盖背景设置。

- A 各级三角数 19,800 / 9,900 / 4,950 / 1,980，B 为 49,920 / 24,960 / 12,480 / 4,992。UV 岛立方体 LOD1 保留 188/188 个接缝位置。B 四级量化包围盒最大相对误差 `4.019e-6`（上限 `1e-3`）。
- B 的 trimesh 为 400 三角。19,800 三角球的 convex 输出 32 个闭合凸块。缺 `LOD` 或 `TEXCOMP` 权限的样本均触发退出码 8。
- B 从同一 normalized 输入独立处理两遍，4 个 LOD GLB、碰撞 GLB 和 `stats.json` 的 SHA-256 共 6/6 一致。`check-size-ratio --max 0.25` 在旧管线上返回 3，新管线上返回 0。
- 试过 meshopt 按大小重排，可再缩小约 64 KB，但现行 `.fpak` 索引编码允许三角形的顶点循环移位，违反仓库逐索引字节往返断言。最终保留原有简化误差、锁边、LOD 比例和量化参数。

## 真实 CC0 样本

任务卡验收①要求至少一个带纹理模型。登记为 `AST-M1-002-CC0-01` 的 Microsoft WaterBottle 带四张原生 2048² PNG，LOD0 实测 **1,734,656 / 8,966,928 B = 19.35%**。六个原始文件共 8,967,656 B。四级 LOD 为 4,510 / 2,254 / 1,128 / 450 三角。颜色、ORM、法线和自发光各有 12 级 mip。`process` 耗时 66.72 s，验收⑧的 30 s 预算适用于 B 的四张 1024² 输入。

下列命令在仓库根目录运行。`GLTF_SAMPLES` 指向 KhronosGroup/glTF-Sample-Assets 的本地检出，原件固定到 LICENSES 台账中的 commit。可在一次性目录中复跑真实闸门。

```sh
set -eu
sample_rev=f0920f5b32d172a30efe3f9257e965918831e6ea
d=$(mktemp -d /data/scratch/m1-002-water.XXXXXX)
trap 'rm -rf "$d"' EXIT
mkdir -p "$d/src" "$d/in/M1-002"
git -C "$GLTF_SAMPLES" archive "$sample_rev:Models/WaterBottle/glTF" | tar -x -C "$d/src"
zip -q -j "$d/in/M1-002/WaterBottle.zip" "$d/src"/*
ap=tools/asset-pipeline/bin/asset-pipeline.mjs
id=AST-M1-002-CC0-01
node "$ap" ingest --incoming "$d/in" --work "$d/work"
unzip -q "$d/work/$id/raw/WaterBottle.zip" -d "$d/work/$id/raw"
node "$ap" normalize --asset "$id" --id prop_water_bottle --input WaterBottle.gltf --work "$d/work"
node "$ap" process --asset "$id" --id prop_water_bottle --work "$d/work"
node "$ap" check-size-ratio --asset "$id" --max 0.25 --work "$d/work"
```

额外抽测主仓真实缓存，结果如下。Kenney `bridge.glb` 加 512² 调色板 PNG 为 18,864 / 42,960 B（43.91%）。`building-type-t.glb` 为 48,780 / 179,066 B（27.24%）。Poly Haven 木箱加 3 张原生 2048² JPEG 为 4,144,164 / 8,155,886 B（50.81%），其中法线占 2,928,813 B。Coast Rocks 为 43.73%。这些资产的单件预算需随内容评估。另有 Kenney `figurine-cube-detailed.glb` 在网格索引编码时报断言，未生成尺寸结果，见 PI-B6-assetlod-2。
